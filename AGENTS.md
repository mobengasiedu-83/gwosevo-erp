# Project instructions

- When a change alters a user-visible screen, permission, workflow, setup step, or operational behavior, update `docs/user-guide/README.md` and the relevant module guide in the same change.
- Keep the in-app User manual in sync with these sources; it renders the maintained Markdown files from `docs/` directly.
- Do not document credentials, tokens, invitation links, personal records, or other secrets in user-facing documentation.
